# Табы и обзор в панели `/plugins` — дизайн

**Дата:** 2026-07-18 · **Статус:** дизайн одобрен, реализация.

## Проблема
Панель `/plugins` вываливает весь каталог claude (сотни доступных плагинов) одним списком —
непрактично: нужное (установленные, источники) тонет. Нужна home-страница и табы.

## Решение — таб-бар + 4 таба
Под шапкой — фиксированный таб-бар, активный таб подсвечен. Вход — на «Обзор».

```
  Обзор   Установленные   Каталог   Источники
 ─────────────────────────────────────────────
```

1. **Обзор** (landing) — не список, а сводка: установлено N (Claude X · Codex Y), доступно M
   в K источниках, источников K. `↑↓`+`Enter` по строкам прыгают в соответствующий таб.
2. **Установленные** — только `installed`, обоих провайдеров секциями (их единицы, поиск не нужен).
3. **Каталог** — только доступные (`!installed`), с инкрементальным поиском и скроллом (уже есть).
4. **Источники** — управление marketplace (add/remove) — существующий режим становится табом.

## Навигация (единая)
| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | вперёд/назад по табам |
| `↑↓` | по списку/строкам активного таба |
| `Enter` | Обзор — прыжок в таб; Установленные — удалить (подтв.); Каталог — установить (подтв.); Источники — удалить источник (подтв.) |
| `^E` / `^U` | вкл-выкл / обновить (везде одинаково — в Каталоге буквы заняты поиском) |
| `a` | Источники — добавить источник |
| ввод текста | Каталог — поиск; Источники (в режиме add) — адрес |
| `Esc` | из ввода/подтверждения — отмена; иначе закрыть панель |

`Tab` больше НЕ включает режим источников (он теперь таб). Цифры `1`–`4` — прыжок на таб во
всех табах, КРОМЕ Каталога (там цифры уходят в поиск; переключение — `Tab`).

- Остальные поля (plugins, index, query, confirm, marketplaces*, marketplace_input/confirm) — как есть.

## Данные
- `app.plugins` не меняется — фильтруется по табу: Установленные → `installed`, Каталог → `!installed`.
- Marketplace-источники грузятся при ОТКРЫТИИ панели (а не только при входе в таб) — чтобы «Обзор»
  сразу показал число источников. Claude — синхронно, codex — воркером (как плагины).
- Действие `plugin_enter` уже решает install/uninstall по `entry.installed` — в Каталоге все доступные
  (install), в Установленных все установленные (uninstall), логика не меняется.

## Компоненты
- `PluginsTab` (enum + `next/prev/label`) — в `app/plugins.rs`.
- `app/plugins.rs` — навигация по табам (ленивую загрузку источников заменить загрузкой при open),
  `visible_plugins()` (фильтр по табу+поиск), счётчики для Обзора.
- `runtime.rs::handle_plugins_key` — маршрутизация по табам (Tab/Shift+Tab, суб-состояния перехватывают).
- `ui/plugins.rs` — таб-бар + рендер тела по активному табу + подсказки по табу.

## Обработка ошибок / край
- Пустой Каталог при поиске → «ничего не найдено»; пустые Установленные → «нет установленных».
- Источники ещё грузятся → в Обзоре «Источники …», в табе Источники — «загрузка…».
- Малый экран — таб-бар (1 строка) + скролл тела остаются (высоты уже считаются saturating).

## Тестирование
- `PluginsTab::next/prev` циклятся правильно.
- `visible_plugins` фильтрует по табу (Установленные — только installed; Каталог — только available+поиск).
- Счётчики Обзора: N установлено (разбивка Claude/Codex), M доступно, K источников.
- Клавиши: Tab листает табы; Enter в Обзоре прыгает в таб; поиск работает только в Каталоге.
- Рендер (TestBackend): таб-бар с активным табом; каждый таб показывает своё; Обзор — сводку.
