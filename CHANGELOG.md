# Changelog

Все заметные изменения clave. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## 0.3.0

### Добавлено

- **Плагин-менеджер — панель `/plugins`.** Единое управление плагинами Claude Code и Codex, не заходя
  в каждый инструмент по отдельности. Табы **Обзор** (сводка), **Установленные**, **Каталог** и
  **Источники**. В каталоге — поиск, установка, удаление, включение/выключение и обновление; сюда же
  подмешиваются плагины **сторонних marketplace-источников**, а не только официальные. У выбранного
  плагина видно описание, автора и источник; бейдж «↑» отмечает доступное обновление. Провайдер
  переключается `←/→` (Claude ⇄ Codex), источники добавляются и удаляются прямо из панели.

### Исправлено

- **Чаты изолированы по каталогу запуска.** Раньше история и «последний чат» были общими на всё
  окружение — открыв clave в другом проекте, можно было увидеть чат предыдущего. Теперь у каждого
  каталога своя история.
- **Лента не двоит, не затирает и не слепляет сообщения.** Дубли и затирание шли от неверной ширины
  эмодзи-маркеров (`⏺`/`⏹`) — высота блока при инлайн-рендере съезжала; отдельно поправлены слипание
  фрагментов токен-стрима и сырые `*звёздочки*` markdown (теперь курсив).
- **`--resume` / `-r`** открывает TUI сразу на списке сохранённых чатов.
- **Структурированные ошибки провайдера** (например, неверная модель) показываются как ошибка с кодом,
  а не как обычный ответ.
- **Лоадер** в фазе рассуждения пишет уровень усилия, а оценку расхода — только когда пошёл ответ.
- **Зависший провайдер больше не морозит clave** — у проверки логина появился потолок по времени.
- Множество мелких правок надёжности UX и прогона.

### Внутреннее

- Резко выросло покрытие тестами (мутационный гейт по ядру TUI и хранилищу) — меньше шансов на регрессии.
- Страж релиза: сборка релиза физически не идёт из «грязного» рабочего дерева.

## 0.2.0

### Убрано

- **Экспериментальный веб-пульт.** Он был сырым и держал на себе лишний жизненный цикл процессов;
  вместе с ним укреплены управление процессами и хранилище состояния. Это ломающее изменение —
  отсюда 0.2.0, а не 0.1.4.

### Добавлено

- **Индикатор git-ветки в футере** — видно, где идёт работа, не переключая окно.
- **Флаг `--version`** — печатает версию и выходит.
- **Человеческий финал прогона** вместо машинного «Clave завершился с кодом N»: сырой код возврата
  в ленте читается как падение, даже когда всё прошло хорошо.
- Панель `?` перегруппирована в две колонки без рамок — влезает целиком.

### Исправлено

- **Футер больше не спавнит `git` каждые две секунды.** Индикатор ветки опрашивал репозиторий по
  таймеру — постоянная нагрузка на ровном месте; теперь обновляется по событиям.
- **Футер не обрезает последний символ** у правого края: терминал рисует «неоднозначные по ширине»
  символы (`→`, `·`) в две клетки, а раскладка считала их за одну.
- **Транскрипт не белеет в скроллбэке.** `Line::styled` терял цвет при прокрутке — стиль строки
  теперь складывается в спаны.
- **Последние строки палитры команд** больше не остаются притушенными навсегда.
- **Неизвестные флаги CLI отклоняются**, а не уходят агенту как текст задачи: опечатка в флаге
  раньше молча превращалась в задание.
- **Ширина текста меряется по отображаемой ширине**, а не по числу символов — кириллица, эмодзи и
  спецсимволы больше не разъезжаются с тем, что реально рисует терминал.
- **Вывод codex изолирован** в приватный временный каталог на процесс — параллельные запуски больше
  не мешают друг другу.
- **Логотип корректно чёрный**: Terminal.app игнорирует truecolor RGB, поэтому используется ANSI.

### Внутреннее

- Футер полностью покрыт мутационными тестами: из 75 мутантов не выживает **ни один**. Раньше
  выживало 29 — то есть код можно было сломать, и тесты бы этого не заметили.
